# Astrid · glass

WebGL glass Astrid orb, restyled to the soft "vibe" reference: frosted white form with a Gaussian edge,
a pale blue pool glowing up from the bottom, a faint pink/cyan fringe and big white pebble eyes.
Open with `?debug` (or press `d`) for tuning sliders. Test params: `?still`, `?yaw=&pitch=`, `?coat=&mode=`, `?noadapt`.

- `v7-bubble.html`: the previous glossy soap-bubble build (standalone).
- `v6-svg.html`: SVG/CSS fallback used when WebGL is unavailable.
- Edit `glass.frag`, then `python3 build.py` to inline it into `index.html`.
